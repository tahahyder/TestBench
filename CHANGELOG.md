# Changelog

All notable changes to TestBench are documented here. This project follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-10-27

### Added

- Local-first YAML-based web, Android, and game test automation.
- Dashboard, interaction recorder, static HTML reports, and CLI.
- Optional AI test generation and healing, disabled by default.
- Optional plugin entry points for drivers, steps, and lifecycle hooks.
- Cross-platform packaging, CI workflows, and documentation foundations.

### Security

- Loopback-only dashboard default, optional token authentication for remote
  binding, origin checks, and local template path restrictions.
